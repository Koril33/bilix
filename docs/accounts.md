# 登录、普通账号与会员权限

## 先查看当前会话

```shell
blx auth status
blx info BV1j4411W7F7
```

`auth status` 会区分未登录、失效登录、普通账号和有效大会员。切换账号重新运行 `blx auth login`，扫码确认后新凭据才替换旧凭据；取消、超时或失败不会覆盖原有登录。`blx user`、`blx user --login` 是相同功能的兼容入口。

`info` 的清晰度表区分“可获取”和页面列出的其他清晰度。下载只能使用当前会话实际拿到的视频流；页面中出现 4K、HDR 等标签，并不代表当前账号能够下载。音轨列表也以实际返回的 AAC、FLAC、Dolby 为准。

| 会话 | 处理方式 |
| --- | --- |
| 未登录 | 下载匿名会话可获取的流；需要登录时先扫码 |
| 普通账号 | 下载登录后可获取的流；会员专属清晰度或音轨可能不可用 |
| 有效大会员 | 可获取范围仍取决于具体视频、地区和单独购买权限 |
| 登录失效 | 状态提示重新扫码；已有 token 文件不等于登录仍有效 |
| 仅试看或 DRM | 明确拒绝下载，不将试看误记为完整正片 |

同一清晰度和音轨在不同视频上可能有不同权限，不能把某个样本的最高清晰度当作所有普通账号的固定上限。

2026-10-02 的普通账号在线权限检查中，16 个样本实际可获取的最高清晰度为 1080P；1080P+、1080P60、4K、HDR、杜比视界、8K，以及所测 FLAC/Dolby 音轨均不可获取。这是本次账号和样本的结果，后续以 `info` 返回的实际流为准。

## 普通账号的下载流程

先检查信息或计划，再开始下载：

```shell
blx info BV1j4411W7F7 --json
blx download BV1j4411W7F7 --dry-run
blx download BV1j4411W7F7 --save "D:/Videos/BiliX 测试"
```

默认使用实际可获取的最高视频清晰度和最高码率 AAC 音轨。自动编码在该清晰度内优先 AVC，其次 HEVC、AV1；不会为坚持 AVC 而自动丢掉更高的 HEVC/AV1 清晰度。`--audio best` 在实际音轨中依次偏好 FLAC、Dolby、AAC，普通账号没有会员音轨时仍可使用 AAC。

指定清晰度不可用时，默认提示并使用不高于请求值的流。要求精确清晰度或编码时加 `--strict`：

```shell
blx download BV1j4411W7F7 -q 1080p --dry-run
blx download BV1j4411W7F7 -q 1080p --strict --dry-run
blx download BV1j4411W7F7 -q 480p --codec HEVC --strict
```

第一条可能降级；第二条在 1080P 不可获取时返回失败，避免脚本把较低清晰度误认成请求的结果。显式选择 `--audio flac` 或 `--audio dolby` 时，没有对应音轨就失败，不会替换为 AAC。

## 多 P、影视和批量

多 P 默认选择全部；链接中的 `?p=2` 选择 P2，显式 `--page` 优先于链接。选集参数支持 `all`、`1,3,5-7`，重复、倒序和越界选集会失败。

```shell
blx download BV12R4y1J75d --page 1,3 --dry-run
blx download "https://www.bilibili.com/video/BV17x411w7KC?p=2" --dry-run
blx download "https://www.bilibili.com/bangumi/play/ss12548" --page 1 --dry-run
```

`ep` 是单集，`ss`/`md` 选择正片列表，默认包含全部正片；电影存在多个语言版本时也可用 `--page` 选择。普通账号对会员影视通常只能试看或不能获取流，程序会在传输前报告对应权限错误；免费正片仍可正常下载。

本轮检查同时覆盖免费与会员选集：`md25577961` 对应番剧的免费第 1 集 `ep1530739` 可获取 1080P，后续所测集数仅有试看权限；`ep29006` 可获取免费正片 1080P。`让子弹飞` 的两个正片语言版本和 `功夫` 的两个版本仅有试看权限。影视首页可能播放预告片，判断正片权限必须以正片选集为准。

批量文件支持 UTF-8 和 UTF-8 BOM，每行一个完整 URL/BV 号，忽略空行和 `#` 注释。某个地址或某集失败仍会继续后续任务；最终有任何失败时退出码为非零。使用文件列表可以避免终端对 URL 中 `&`、空格等字符的处理；直接输入完整链接时用引号包裹。

```shell
blx info --file videos.txt --json
blx download --file videos.txt --quiet
```

JSON 不包含 Cookie 或签名 CDN 地址。普通账号信息仍属于个人信息，提交公开问题时可只提供视频地址、软件版本、清晰度/编码/音轨参数、错误提示和 `doctor` 结果。

## 已有文件与故障排查

下载前已有同名文件会跳过。需要重下旧版本生成的文件时加 `--overwrite`；新下载校验、合并并提交成功前，旧文件会保留。失败会保留输出目录中的 `.bilix-*` 临时目录，错误消息会给出位置；目前不自动续传。

```shell
blx doctor
blx config
blx auth status
blx download BV1j4411W7F7 --overwrite
```

`doctor` 只检查本地环境，不验证 Bilibili 网络或账号权限。网络/API 失败可以稍后重试；清晰度/音轨不可获取先查看 `info`，不要通过重复登录来假定提升权限。只有状态明确失效或需要切换账号时重新扫码。

普通账号在线验证应覆盖可用清晰度/编码、请求不可用清晰度的降级和 strict 失败、音轨选择、免费影视正片、会员影视拒绝、多 P、批量继续处理、中文目录、已有文件跳过/覆盖和 JSON 输出。登录退出的破坏性路径使用隔离配置目录和虚构凭据测试，避免在线验证期间改变当前账号。
