# 登录、账号权限与故障排查

## 登录与凭据

```shell
blx auth login
blx auth status
blx auth status --json
blx auth logout
```

登录在用户配置目录生成二维码 PNG；使用手机 Bilibili App 扫码并确认。登录成功后保存规范化 Cookie。切换账号时重新运行 `auth login`，只有成功后才替换原有凭据；取消、超时或失败不覆盖已有登录。

`auth status` 区分未登录、失效登录、普通账号和有效大会员；年度大会员与到期时间单独展示。文件存在不等于登录仍有效。`auth logout` 删除本地 token，不代表服务器会话失效；账号安全处理见 [安全政策](../SECURITY.md)。

配置位置用 `blx config` 查询。旧用户配置目录的 `token.txt` 在内存中兼容 Set-Cookie 属性，不改写原文件。旧根目录的 `cookie.txt` 不再自动读取，需重新扫码。

## 权限判断

`blx info URL` 展示当前会话可获取的流。页面显示的清晰度标签不等于实际授权；同一个账号在不同视频上也可能取得不同清晰度或音轨。

| 会话或内容 | 行为 |
| --- | --- |
| 未登录 | 使用匿名会话实际可获取的流 |
| 普通账号 | 使用登录后可获取的流；会员专属画质/音轨可能不可用 |
| 有效大会员 | 仍受视频、地区与单独购买权限限制 |
| 登录失效 | 提示重新扫码 |
| 仅试看或 DRM | 在传输前拒绝，不把试看记作完整正片 |

自动编码先保留实际可获取的最高清晰度，再偏好 AVC、HEVC、AV1。请求不可用清晰度时，默认提示并降级到不高于请求值的流；`--strict` 要求清晰度与编码匹配。显式 `--audio flac` / `dolby` 没有对应音轨时直接失败；`best` 依次偏好 FLAC、Dolby、AAC。

## 推荐流程

```shell
blx auth status
blx info BV1j4411W7F7
blx download BV1j4411W7F7 --dry-run
blx download BV1j4411W7F7 --save "D:/Videos/BiliX"
```

影视首页可能展示预告片；本程序以正片选集判断权限。`ep` 下载单集，`ss` / `md` 默认选择全部正片，可用 `--page` 选择语言版本或集数。多 P、批量、路径与配置说明统一见 [用法文档](usage.md)。

## 排错

### DRM 与试看

DRM 标记来自播放数据中的 `is_drm`，不是按电影类型、会员状态或画质猜测。登录只确定账号可访问的内容；DRM 还涉及平台授权的解密与播放流程，当前 BiliX 不支持这种媒体。更换 FFmpeg、降低画质或重新登录本身不能保证解决 DRM。使用官方客户端播放，并确认该内容是否提供官方离线缓存。加密媒体的授权与播放机制可参考 [W3C Encrypted Media Extensions](https://www.w3.org/TR/encrypted-media/)。

先运行 `blx auth status` 与 `blx info URL --json`，检查当前会话、`is_drm`、`is_preview` 与实际可获取的流。未登录响应不能代表付费账号的结果；如果正常登录后接口提供普通、非试看且非 DRM 的流，程序可按通常流程处理。反馈问题时只提供这些布尔状态、版本、公开地址与脱敏错误，不提供 Cookie 或媒体签名 URL。

`ss` / `md` 会处理全部正片选集，电影的多个语言版本也分别计数。例如 `ss46055` 在 2026-10-03 的选集接口中包含“原版”（`ep777109`）与“中文”（`ep777157`），因此可能显示失败 2；这不是同一项重复报错。当天未登录的官方网页播放接口对两项均返回 `is_drm=true`、`is_preview=1`，未测试用户的登录会话。可用 `--page 1` 或具体 `ep` 地址选择单项，但选集不会解除 DRM。

### 常见问题

| 症状 | 处理 |
| --- | --- |
| 登录失效 | 重新运行 `auth login` |
| 清晰度/编码/音轨不可用 | 用 `info` 查看实际流；调整参数，或在具备授权的账号下重试 |
| 会员电影只能试看 | 核对账号的正片授权与单独购买权限 |
| DRM 保护 | 当前不支持下载；使用官方客户端播放，参见上面的说明 |
| FFmpeg 不存在 | 用 `doctor` 检查，安装完整工具或指定 `--ffmpeg` |
| 网络或 API 失败 | 稍后重试，保留脱敏错误信息；`doctor` 不验证网络 |
| 已有文件被跳过 | 默认行为；确认需要重下后使用 `--overwrite` |
| 下载/合并失败 | 错误中给出 `.bilix-*` 位置；目前不自动续传，不直接删除旧目标 |

提交问题只提供版本、操作系统、可公开地址、参数与脱敏错误，不提供账号 UID、姓名、Cookie 或签名媒体地址。历史在线样本仅代表当时权限，详见 [验证记录](validation-1.4.0.md)。
