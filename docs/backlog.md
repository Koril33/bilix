# 未完成需求与功能登记

更新日期：2026-10-14（Asia/Shanghai）。以已发布 **1.8.0**、当前源码和[验收记录](validation-1.8.0.md)为基线。本表只登记尚未交付的契约及明确接受的能力边界，不重新列历史版本的已完成工作。开发、测试和部署中的问题见[流程问题登记](workflow-issues.md)，版本安排见[路线图](roadmap.md)。

状态含义：**未做**表示尚无完整产品实现；**已实现待验证**表示有实现但缺对应验收；**接受限制**表示维护者接受的本版边界，不能写成已验证；**实际缺陷**表示已有失败证据或用户报告，仍须区分报告、复现与根因。优先级：P0 阻止受影响候选发布；P1 优先维护；P2 独立功能排期；P3 可选增强，尚无版本承诺。表中优先级是维护建议，不改变已冻结版本范围。
