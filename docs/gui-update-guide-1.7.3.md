# BiliX 1.7.3 更新指南：简洁 GUI

> 历史设计/评审：保留当版基线、建议和决策。当前行为见 [使用文档](README.md#当前使用与开发)，未完成功能见 [backlog.md](backlog.md)，缺陷与流程问题见 [workflow-issues.md](workflow-issues.md)。构建、测试与发布从 [handoff.md](handoff.md) 进入，不直接执行下方旧版命令。

更新日期：2026-10-10。状态：**已按本指南实施，发行结果以验收记录为准**。行为基线为 1.7.2；本指南依据维护者对”小巧精致、降低使用难度”的要求，以及[易用性评估](gui-usability-assessment.md)的第一步、第二步制定。经代码对照评审后补充了布局细化、阶段拆分与工程约束。

## 1. 版本目标与范围

1.7.3 让用户直接完成“粘贴链接 → 按需选择选集 → 下载 → 找到文件”。主窗口短而清楚，复杂信息按需打开。继续使用 Qt Widgets，复用已有操作和任务内核，下载稳定性优先于新增能力。

“小巧”首先指窗口、控件数量与操作步骤；本版不承诺明显缩小 EXE 或内存。保持现有依赖，不引入 WebView、第三方主题库、外部字体或封面请求，不为装饰增加加载开销。

| 本版必须完成 | 范围边界 |
| --- | --- |
| 局部交互改善 | 主按钮、更多选项、选集批量勾选、时长/画质文案、账号提示、动作启用、文件打开与 Ctrl+Enter；展示层（U1a）与交互（U1b）分步交付 |
| 主页面重排 | 一个主窗口，简洁添加区、统一下载列表、常驻状态；去掉顶层四标签和内部三标签 |
| 按需交互 | 输入附近的解析摘要与选集入口；独立文件预览、任务详情和设置对话框 |
| GUI 组件与数据适配 | 逐步拆分 MainWindow；统一显示来源和任务，同时保留稳定 ID、快照与历史 |
| 对应文档与验收 | 使用说明、定向 GUI 检查、版本/发行材料一致 |

本版继续采用**主动解析**。自动解析、防抖与部分缓存复用、动态限制多视频画质列表、拖放/自动剪贴板检测另行评估。运行中追加、单项取消/移除、速度/ETA、GUI 偏好持久化、主题切换、公开协议与其他 B 功能继续留在后续功能版。Ctrl+Enter 是本版的单项交互改善，不代表 B-07 整体交付。

本指南约束 1.7.3 的 GUI 布局和交互；[1.7.x 基础指南](cli-gui-ux-review.md)中的身份、快照、事务、权限、配置和安全语义继续适用。CLI 命令、输出、退出码和下载策略不因 GUI 改版改变。第一步和第二步都完成后才冻结 1.7.3，不能只完成文字调整就宣称整版完成。

## 2. 目标布局

### 2.1 主窗口

目标默认尺寸约 **820–880 × 620–680**，最小尺寸约 **700×540**，均为逻辑像素。开发中用实际中文字体和 DPI 检查后在范围内取值；尺寸是布局目标，不以压小字体、截断操作或超出可用屏幕为代价。已有按屏幕可用区域限制窗口尺寸的保护继续保留。

```text
┌ BiliX 图标与名称                  [凭据待验证 ▾] [设置] ┐
│ 视频链接 / BV 号                       [解析] [更多 ▾] │
│ ┌ 每行一个链接；输入框可容纳约 2–3 行 ───────────────┐ │
│ └───────────────────────────────────────────────────┘ │
│ 已解析 1 个视频 · 示例标题 · 已选 3 / 12 集 [选择选集] │
│ 保存到 [目录 ................................] [选择] │
│ 画质 [最高可用 ▾] [更多选项 ▾] [文件预览] [下载]      │
│                 严格匹配 · 覆盖同名文件（启用时显示） │
│ 下载列表  [全部 ▾]                         [列表操作 ▾]│
│ ┌───────────────────────────────────────────────────┐ │
│ │ ▾ 视频 A · 3 集                                    │ │
│ │     P1  下载中      视频 72% · 音频 80%              │ │
│ │     P2  等待                                       │ │
│ │     P3  已完成                                     │ │
│ │   视频 B  读取失败 · 请检查网络                     │ │
│ └───────────────────────────────────────────────────┘ │
│ 正在下载 · 已完成 1 项 / 已发现 3 项    [取消本批下载] │
└───────────────────────────────────────────────────────┘
```

这是信息布局示意，不要求按文本绘制控件。统一列表采用 QTreeView + QAbstractItemModel 实现（该选择便于按稳定 ID 更新、筛选，并避免给每行创建控件；性能以候选实测为准），也可在信息结构不变前提下使用带行类型的单列表适配。

底部状态区（`正在下载 · 已完成 …` 及 `[取消本批下载]`）用固定的 QWidget 布局替代 `QMainWindow.statusBar()`，以明确固定底部布局；Qt statusBar 本身也支持放置控件。去掉独立的全局 QProgressBar；当前操作进度改为列表行内显示（复用现有 kind=”progress” 的视频/音频分别百分比），底部只保留操作状态文字与已有计数。

下载列表为空时，在列表区域显示居中的短提示，例如”在上方粘贴链接并点击下载”，不显示空表头或空白区域。

- 去掉整个下载页外层的 `QScrollArea`，下载列表获得剩余高度并独立滚动。状态与取消入口固定在底部，输入和开始操作固定在上部。
- 空闲默认状态的添加区控制在约 220–260 像素高；解析摘要最多两行（多来源摘要规则见 Section 3.1）。长标题省略，完整信息在详情中查看。
- 未解析时隐藏摘要；解析时在相同位置显示”正在解析…”及取消入口，错误就近提示。不得靠自动切换到窗口底部才能看到结果。
- “更多”收纳导入 UTF-8 链接列表等低频输入操作；已存在的导入能力保留。用户直接 Ctrl+V 粘贴到输入框即可，不另设”粘贴”按钮。
- “更多选项”以对话框打开，与选集对话框和设置对话框形式统一，在所有窗口尺寸下不影响主布局。选集、预览、详情和设置也按需打开，主窗口不常驻大详情框。
- 小窗口可将目录与操作分成两行；保留下载、取消和列表的可见性，不新增整页滚动。独立对话框内部必要时可滚动。

### 2.2 视觉约束

复用 1.7.2 图标。顶部用小图标和产品名，不增加大型横幅。只强调“下载”主按钮，其他操作保持次级样式；取消明确可见，但不与下载抢同等注意力。

优先使用系统字体、平台控件与正常对比度，以间距、对齐和少量分隔线建立层级。减少围住每块内容的 GroupBox。建议间距采用 8/12/16 像素，普通控件高度约 28–32 像素；以真实字体与缩放可读性为准。图标操作提供文本或工具提示，键盘焦点清楚，不依赖仅悬停才出现的按钮。

“精致”不需要首版增加动画、配色选择、主题系统或每行多个常驻按钮。优先保证空态、忙碌、失败和完成时均有清楚且一致的布局。

## 3. 输入、解析与选集

### 3.1 基本路径

1. 用户粘贴链接，选择目录与画质，可以直接下载；不强制先联网解析。
2. 需要看标题或选部分内容时，点击输入旁常驻的“解析”按钮。解析完成后，输入下方显示摘要和“选择选集”；未解析时用简短提示说明解析后可选集，不增加另一套解析按钮。
3. 点击“选择选集”打开对话框，勾选完成后主界面显示已选数量。下载仍以点击时的参数创建快照。
4. “文件预览”是独立的次级操作，不是所有下载的强制步骤。

下载前清晰说明默认选集：普通多 P 链接默认全部，明确带 `?p=` 的链接默认指定 P；番剧沿用现有发现/EP 语义。文案和界面不得将指定单集偷偷变成整部下载。

解析摘要控制在两行以内，具体文案按来源数量区分：

| 场景 | 摘要文案 |
| --- | --- |
| 单来源 | `已解析 · 示例标题 · 已选 3 / 12 集 [选择选集]` |
| 多来源全部成功 | `已解析 5 个视频 · 已选 28 / 60 集 [选择选集]` |
| 多来源部分失败 | `已解析 3 / 5 · 2 个读取失败 [选择选集]` |
| 正在解析 | `正在解析（3 / 5）… [取消]` |

多来源时不逐条列标题，具体信息进选集对话框查看。

### 3.2 选集对话框

单个视频显示标题、作者、格式化时长、选集列表和已选数量。多个输入时在对话框内提供视频选择，逐来源维护勾选；主窗口只展示概览，不纵向堆叠 20 张解析卡。

提供“全选 / 全不选 / 反选”，作用于当前视频，并提供可选的范围输入，例如 `1,3,5-7`，通过“应用”明确更新当前勾选。批量范围如需应用到全部视频，必须是独立明确动作，不能改变其他来源却不提示。

勾选是已经解析来源的唯一选择结果。范围字段是编辑勾选的工具，不再与勾选互相暗中覆盖。未解析的直接下载继续支持现有范围规则。任何来源全不选时，按现有校验阻止开始并指明对象，不把空选择当全部，也不静默跳过该链接。

选集列表在对话框中滚动；主窗不因 50 集内容增加高度。时长用 `mm:ss` 或 `h:mm:ss`，无法确定时显示“未知”，不以零冒充已知时长。

### 3.3 数据失效与画质

1.7.3 不做缓存身份迁移：保留输入编辑后清除解析结果、generation 防过期和账号变化后失效的规则，并提示需要重新解析。空白编辑保留解析、排序重映射和重复 URL 缓存复用都不作为本版交付项。

画质保留“最高可用”及现有全部选项，只隐藏内部数字编码，不改传入 planner 的值。解析详情可展示当前视频实际可获取的媒体；不以网页宣称的画质代替实际流，不用第一个视频的结果限制整个列表。

登录后未必增加画质；多 P / 番剧其他选集的媒体与权限仍在预览/执行时分别检查。提示使用“实际画质取决于视频与当前账号权限”等准确文字，不承诺解锁。

## 4. 更多选项与目录

“更多选项”以对话框打开（与选集和设置对话框形式统一），包含视频编码、音频、严格匹配、覆盖及直接下载的范围规则。保持现有 auto / AAC / 不覆盖 / 不严格等默认值，不新增改变选择策略的兼容性或小文件预设。

| 界面文字 | 必须解释的行为 |
| --- | --- |
| 视频编码 | 自动、AVC、HEVC、AV1；具体可用情况以视频与账号为准 |
| 音频 | 指定音频不可获取时会失败；不能描述为总会自动替代 |
| 严格匹配画质和编码 | 指定要求不可获取时不下载；普通模式允许现有降级策略 |
| 替换同名文件 | 新文件下载、校验和合并成功后才替换旧文件 |
| 只下载部分选集 | 已解析时应用到勾选；未解析时使用现有范围规则 |

关闭对话框后，严格、覆盖、自定义选集及其他非默认选项仍以短摘要可见，不能只显示一个含义不明的”已配置”标记。默认情况下不重复列出六项设置。

主窗口只保留“保存到”这一处本次目录入口；“默认目录”放设置，明确用于尚未被手动覆盖的后续输入。保持现有配置优先级、`_output_edited` 或等价语义，不默默持久化本次选择，也不把 GUI 表单写成 CLI 默认。

设置被环境变量覆盖时，在对应字段旁解释保存的文件值和当前实际值。普通状态下将技术来源说明折叠到详情，不能因精简而隐藏正在生效的覆盖。

## 5. 统一下载列表与动作

### 5.1 行与身份

统一列表展示本窗口内跨批次记录。按一次添加的视频请求分组，展开显示选集任务；尚未发现任务的读取失败/取消请求也显示独立行，并能重新读取。不能因为没有 task 就从列表消失。

相同 URL 的不同添加仍是不同请求。显示以 `request_id` / `task_id` 关联，不按标题、URL 或 P 序号合并。一个任务的重试继续更新该任务最新尝试，详情保留旧尝试及每次所属批次；请求重读保留原请求关联。

如完成统一树成本超出预期，可采用带行类型的单列表适配，但必须完整保留来源失败和任务行为。不能退回三标签并宣称布局目标完成，也不强制为界面重写 Session 或建立数据库。

### 5.2 列与状态

默认只展示“视频 / 选集、状态、进度”三个主要信息，完整路径、ID、编码、尝试和错误类别放详情。失败行展示一条安全且可读的原因，长内容省略并可打开详情。

筛选采用一个紧凑下拉：全部、等待、处理中、完成/跳过、失败、取消；无需铺开六个按钮。完成与“已存在，跳过未校验”的文字仍分别显示，不能一起改叫“下载成功”。来源失败同样参与失败筛选，任务筛选按最新尝试判断。

存在子任务时分组标题汇总子任务状态；过滤后的父行不能成为”重试整个视频”的隐式入口。数量明确写”任务”或”链接读取失败”，避免将一个未发现内容的来源算成一项已完成媒体。批次历史汇总在任务/来源详情对话框中保留（通过详情底部的”所属批次”区域查看），后续重试不改写旧汇总。

复用现有视频/音频进度、未知长度字节与阶段事件，不新增速度或 ETA。下载到 100% 仍需校验/合并，不能提前显示完成。底部状态区显示当前操作与已有计数，不添加磁盘剩余空间等额外查询。

### 5.3 操作规则

选中行后通过右键菜单、键盘菜单或紧凑的选中项菜单操作；批量动作放”列表操作”。不恢复四排常驻按钮，不为每一行创建多个 QWidget。

“列表操作”菜单包含：重试全部失败、重试全部取消、清除已完成/跳过记录、清除失败/取消记录。仅在对应状态的记录存在且空闲时启用各菜单项。

| 对象/状态 | 允许动作 |
| --- | --- |
| 已完成且输出存在 | 打开文件、打开所在目录、复制路径、详情；双击打开文件 |
| 跳过且已有文件存在 | 同上，详情明确未再次校验 |
| 失败/取消的任务 | 原参数重试、当前参数重试、详情；现有可用输出另按路径检查 |
| 读取失败/取消的来源 | 重新读取（原参数/当前参数）、详情；不伪装成已锁定媒体的任务重试 |
| 等待/进行中 | 详情；已存在文件/目录可按现有检查打开；双击打开详情 |
| 无选择、不可用路径或忙碌 | 对应动作禁用或给出具体原因，不出现可点但无效的重试按钮 |

默认重试使用所选任务最新失败/取消尝试的快照。使用当前设置前继续显示数量、目录、媒体选择、严格、覆盖与 FFmpeg 摘要并确认。批量失败重试与取消重试分开，不暗中重下成功任务。

分组父行只用于展开或看汇总；重试选择明确的任务/失败来源，不自动把过滤隐藏的孩子纳入操作。清除记录仅空闲时可用，菜单文字明确“清除已完成/跳过记录”或“清除失败/取消记录”，不删除文件、不改旧批次统计。

## 6. 预览、详情、设置与账号

| 按需窗口 | 内容与约束 |
| --- | --- |
| 文件预览 | 复用 `run_preview`，每项显示实际媒体、路径、新建/跳过/替换/阻止及警告。取消或失败不清历史；预览不创建任务或写文件。顶部说明它是时刻快照，执行重新检查。 |
| 任务/来源详情 | 标题、当前状态、安全原因、实际/计划路径、当前参数、重试历史和批次汇总。ID 等放折叠技术详情；现有安全元数据 JSON 复制能力保留，本版不新增公开诊断导出协议。 |
| 设置 | 一个对话框，账号、下载设置、关于与诊断分区；复用扫码/退出/查询状态、目录/FFmpeg 配置保存、打开配置目录和诊断。版本与图标保留。 |

账号状态常驻主窗口，点击可进入设置的账号区。四种状态的控件文字与行为：

| 状态 | 控件文字 | 点击行为 |
| --- | --- | --- |
| 未保存凭据 | `未登录 ▾` | 打开设置 → 账号区 |
| 已保存但未验证 | `凭据待验证 ▾` | 打开设置 → 账号区 |
| 已验证登录 | `已登录：昵称 ▾` | 打开设置 → 账号区 |
| 已失效 | `登录已失效 ▾` | 打开设置 → 账号区 |

启动保持离线，不能为了状态徽标额外发请求，也不能把本地文件存在称为已登录。已验证后可在账号区展示会员状态，主窗口不堆 UID/等级。

1.7.3 保留一个活动 worker / 批次。下载时输入、解析、开始、重试以及会改变账号/配置或启动另一操作的控件仍禁用；用短提示“当前下载结束后可添加新链接”解释。可以筛选、查看详情和打开已有输出，也可以查看设置，但保存、登录、退出、状态查询、诊断等会冲突的动作不可启动。

取消使用明确文字：“取消本批下载”“取消解析”“取消预览”等；请求发出后显示“正在取消…”，等待清理结束，不立即宣称已取消。当前任务结束前不能开启新操作。退出活动操作的确认与等待机制继续保留。

## 7. 键盘与可访问性

- Ctrl+Enter 触发下载，与下载按钮使用同一校验与忙碌规则；中文输入法正在组合时不得提交下载。普通 Enter 在多行输入中仍换行。
- Tab 顺序按输入、输入操作、目录、画质、更多选项、预览、下载、列表、取消组织。不让多行输入吞 Tab，不取消已有输入法占位提示保护。
- 选集勾选可用键盘，菜单与对话框可通过键盘打开/关闭。Esc 关闭空闲对话框；有活动操作的窗口仍按现有取消规则处理，不能销毁仍使用中的 worker。
- 对话框尺寸受可用屏幕限制；长标题、中文/空格路径、高 DPI 和系统主题下的内容仍可读。短提示优先行内显示，真正阻断的失败继续使用安全错误提示。
