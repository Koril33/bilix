维护者于 2026-10-10 指定 1.7.2 为图标更新版并简化本版测试，取代 2026-10-08 将 B 排入 1.7.2 的安排。B 整体顺延至后续功能版；公开机器协议仍须独立 schema 和兼容契约，不因产品版本安排省略前置。

维护者随后指定下一版 1.7.3 聚焦[易用性评估](gui-usability-assessment.md)的第一步（局部改善）和第二步（布局）。以“小巧精致、降低使用难度”为目标，继续主动解析，不改下载内核；自动解析/缓存迁移、运行中追加/单项取消、速度/ETA 和 GUI 偏好等不成为本版门槛。Ctrl+Enter 单项改善不代表 B-07 完成，B 功能版仍单独排期。

## 发布与验收

沿用 [持续测试规范](testing.md)、[验收模板](validation-template.md)及 [发布流程](releasing.md)。1.7.1 不沿用 1.7.0 的桌面、性能或缺失检查结论；五项未闭环不发布。网站交付以 `site/bilix.html` 修改、验证与 Git 提交为完成条件，维护者自行复制到服务器，不将线上部署作为此次阻塞项。

升级使用原始 1.7.0，同时保留原始 1.6.0 作为长期基线。公开文件与标签保持不可变。新 Windows 安装器保护不改变已发布 1.6.0 安装器的覆盖行为，断电/强杀恢复仍单独排期。

后续 B 功能版先落实任务级取消作用域与线程安全队列，再冻结流尝试/采样/速率语义及公开 JSONL；config、stdin、诊断、偏好使用共享服务并保持原命令兼容。具体功能与用例以指南 B 为准，不能只修改按钮文字冒充实现。

1.7.3 按[版本指南的定向验收](gui-update-guide-1.7.3.md#9-定向验收)检查 GUI 变化，复用既有自动化与下载行为基线；候选版本的原生 GUI 结果必须实际记录，不能将历史通过直接写为本版通过。共享内核与安装器输入未变时，不因布局调整重做完整权限/安装故障矩阵；发生相关代码变化则按影响补测。维护者已授权实施并简化本版测试；实际执行与未测范围以 1.7.3 记录为准。
