# CLI/GUI 版本规划

更新日期：2026-10-10。唯一详细开发指南为 [BiliX 1.7.x 开发指南](cli-gui-ux-review.md)。

| 版本 | 必须完成的范围 | 当前状态 |
| --- | --- | --- |
| 1.7.0 | 指南 A 的任务、信息、预览、会话重试、配置、CLI 与安装器实现 | 已发布；接受的未验证范围保留在 [原始验收记录](validation-1.7.0.md) |
| 1.7.1 | 各支持平台真实桌面/IME/DPI/小屏及完整 Wayland；Windows 磁盘耗尽与用户正常取消；原生首帧/内存/千项交互基线；新版页面提交；验证脚本版本一致性门槛 | 已发布；五项收尾与最终材料通过，GitHub/PyPI公开回验完成，见 [1.7.1 记录](validation-1.7.1.md) |
| 1.7.2 | 原创圆角底板应用图标，统一 GUI、CLI 和安装器 | 图标更新版；按维护者要求执行定向检查，见 [1.7.2 记录](validation-1.7.2.md) |
| 后续功能版（版本待定） | 指南 B-01 至 B-07 全部：追加队列/单项取消、速度/传输 ETA、JSONL/公开错误码、config 编辑、stdin、诊断导出、GUI 偏好/快捷键/主题 | 待开发；所有 B 前置与验收仍须满足 |
| 独立排期 | 指南 C：跨重启历史、暂停/续传、并发/限速、自动更新/新平台、清理及额外媒体导出 | 不进入 1.7.1 或隐含并入 1.7.2 |

维护者于 2026-10-10 指定 1.7.2 为图标更新版并简化本版测试，取代 2026-10-08 将 B 排入 1.7.2 的安排。B 整体顺延至后续功能版；公开机器协议仍须独立 schema 和兼容契约，不因产品版本安排省略前置。

## 发布与验收

沿用 [持续测试规范](testing.md)、[验收模板](validation-template.md)及 [发布流程](releasing.md)。1.7.1 不沿用 1.7.0 的桌面、性能或缺失检查结论；五项未闭环不发布。网站交付以 `site/bilix.html` 修改、验证与 Git 提交为完成条件，维护者自行复制到服务器，不将线上部署作为此次阻塞项。

升级使用原始 1.7.0，同时保留原始 1.6.0 作为长期基线。公开文件与标签保持不可变。新 Windows 安装器保护不改变已发布 1.6.0 安装器的覆盖行为，断电/强杀恢复仍单独排期。

后续 B 功能版先落实任务级取消作用域与线程安全队列，再冻结流尝试/采样/速率语义及公开 JSONL；config、stdin、诊断、偏好使用共享服务并保持原命令兼容。具体功能与用例以指南 B 为准，不能只修改按钮文字冒充实现。
