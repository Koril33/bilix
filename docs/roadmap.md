# CLI/GUI 版本规划

更新日期：2026-10-05。本轮按 A 范围实现 1.7.0，维护者决定简化后续测试并发布；真实桌面等未验证范围及各渠道公开核验以[1.7.0 验收记录](validation-1.7.0.md)为准。没有宣称 A 全部验收通过；隔离原型不替代产品证据。

**唯一详细开发指南为 [BiliX 1.7.x 开发指南](cli-gui-ux-review.md)。** 本页只保留范围索引，不维护另一套优先级、状态契约或验收标准。

| 范围 | 内容 | 版本策略 |
| --- | --- | --- |
| A：1.7.0 必须完成 | A-01 最小任务/尝试/事件；A-02 信息/逐视频选集；A-03 会话记录/筛选/快照重试；A-04 冲突预览；A-05 首屏；A-06 配置来源；A-07 账号/整批取消/退出；A-08 CLI 示例；A-09 安装器；A-10 发布验收 | 全部 A 与门槛完成才宣布本文范围的 1.7.0 完成 |
| B：有条件扩展 | 运行中追加/单项取消、速度/传输 ETA、JSONL/公开错误码、config 修改、stdin、诊断导出、额外偏好/主题 | 完成前置/验收后才能在 1.7.0 冻结前纳入；未纳入默认转下一功能版候选 |
| C：独立排期 | 跨重启历史、暂停/续传、并发/限速、更新、新平台、清理/旧文件检查/其他媒体导出 | 不进入 1.7.0，不作为模型预留的隐含承诺 |

1.7.x 是 1.7.0 及修复维护线，不承诺通过 patch 逐步加入全部 B。新增公开功能默认用下一功能版；可靠性修复可先单独出修复版，仍须对应验收。

## 实施次序

1. D0 保留原始 1.6.0 包/哈希，采集基线，准备真实账号/桌面环境。
2. D1 最小共用任务与配置来源；帮助、离线账号与安装器可并行。
3. D2 信息/选集、独立预览、会话记录与快照重试。
4. D3 首屏/取消/退出/CLI、基础键盘/小屏、安装器可靠性。
5. D4 冻结实际范围并执行源码、分发、升级、业务与桌面验收。

保留旧批次记录不等于运行中追加；A 仍串行、单活动 worker。默认重试被选失败/取消尝试的快照，显式当前设置只影响新尝试。预览是时点预测，执行/提交再次判断，原子提交保护不变。

## 发布与未来边界

沿用[测试规范](testing.md)、[版本模板](validation-template.md)与[发布流程](releasing.md)。主平台桌面、真实业务与原始 1.6.0→候选升级归 A，不后置到恢复/并发。原型证据见[设计验证](validation-1.7-design.md)，不替代正式候选验收。

新 Windows 安装器在改文件前拒绝覆盖较高同渠道版本；无法保证已发布 1.6.0 旧安装器也拒绝覆盖新版，须实测并披露。Linux 显式降级遵循包管理器。所有渠道保护用户数据，原始发行包/标签不改。

持久化需格式/迁移/中断模型，续传需身份/授权/Range/长度/媒体校验，并发需任务隔离/资源预算。并发可独立于续传，不要求固定“持久化→续传→并发”顺序。更新、平台与媒体导出独立验收；完整契约及用例以指南为准。
