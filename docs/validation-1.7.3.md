# 1.7.3 GUI 更新记录

日期：2026-10-10（Asia/Shanghai）。维护者授权实施并发布 1.7.3，要求测试集中 GUI 变化、尽快交付，全面矩阵留给后续大版本。本记录保留实际执行范围，不将历史验收或设计用例等同本版全部通过。

## 改动与边界

GUI 使用紧凑主窗口、QTreeView / QAbstractItemModel 统一下载列表与固定底部状态；选集、预览、更多选项、详情和设置按需打开。逐来源勾选、明确应用范围、四态账号、Ctrl+Enter 与 IME 保护、按状态启用动作和快照重试已接入。列表以稳定 ID 展示来源与任务；批量状态筛选最多每 35ms 合并刷新，普通进度只重画对应行。

共享下载内核、CLI 行为、依赖、FFmpeg、权限与安全提交策略不变，产品版本统一为 1.7.3。运行中追加/单项取消、速度/ETA 与持久偏好未加入。
