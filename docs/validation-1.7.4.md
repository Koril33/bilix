# 1.7.4 GUI 更新与发布记录

日期：2026-10-10（Asia/Shanghai）。维护者授权按修订方案实施并尽快发布，测试集中相关 GUI 边界与发行包，不执行全面下载/安装/平台矩阵。本文记录本版实际执行结果，公开发布核对见末节。

## 实现范围

主窗口以列表为中心，提供菜单、工具栏、五类计数筛选和 QStatusBar；新建下载在单一非模态对话框内完成。输入稳定约 500ms 自动解析，逐行本地错误与网络失败分别展示，合法成功来源可明确勾选后提交。IME、旧事件/旧 done、关闭草稿、显式取消与等待当前操作均受保护。

本地合法 token 自动验证账号，登录后刷新账号，网络失败不误判过期；外部凭据变更使旧结果失效。自动读取、下载、预览和诊断保持一个活动操作，下载中只能准备下一份草稿。原参数重试沿用快照，调整参数后重试固定身份并明确确认。

Fusion 基础浅深色、SVG 操作图标、delegate 进度绘制、独立 GUI 偏好、设置确定/取消/应用及安全诊断复制已接入。最小化可进入托盘，恢复原窗口，关闭/菜单退出均执行显式退出；每个真实下载批次结束通知一次，取消无完成通知，无能力时回退至任务栏/列表摘要。

下载内核、CLI 行为、依赖范围和 FFmpeg 不变；无运行中追加、单项取消、任意移除、暂停续传、媒体并发或跨重启历史。GUI 偏好仅保存在配置目录 gui.ini，不保存 token、草稿或解析结果；覆盖不跨会话恢复。

## 已执行的定向检查

- Windows / CPython 3.14.8 / Qt 6.11.2：62 项相关 GUI、构建身份、发行清单、deb 打包与许可检查通过，其中 GUI 40 项。新增 11 项定向检查覆盖自动解析、部分成功/重复来源、主线程回调、旧结果拒绝、IME/取消、忙碌草稿、账号有效/过期/网络失败、外部凭据删除、托盘恢复、通知去重和设置偏好。
- Ruff 检查及相关 Python 文件格式通过。使用当前锁定 curl-cffi 0.16.3；网络测试均为本地可控模拟，无真实 token 或媒体传输。
- Windows 原生 Qt 窗口在当前 125% 缩放下实际检查 700×540 主窗口，列表高度 377 逻辑像素；浅/深色切换、自动选集解析、设置、真实托盘隐藏/恢复与空闲退出通过。截图与结果保存于忽略目录 build/release-1.7.4/。这不是原生 IME 或全部 DPI 矩阵。
- Ubuntu 22.04 / X11（xcb）原生窗口实际检查托盘隐藏/恢复、无托盘时普通最小化回退与空闲退出，通过；桌面报告托盘和通知接口可用。
- Windows GUI 单文件/独立目录及 Ubuntu 22.04 GUI 最终冻结程序离线启动检查通过，SVG 自检同时检查品牌与操作图标。Windows CLI 构建与原有启动检查通过，CLI 不包含 Qt。

## 本版未执行的范围

不重复匿名/普通/会员真实下载权限、全平台安装/升级/卸载故障注入、四 Linux 发行版桌面/Wayland、原生中文 IME、全档系统 DPI、高对比系统模式或千项性能矩阵。下载/账号的模拟事件不代替真实服务验证。通知受操作系统设置影响，supportsMessages 为真不保证最终送达；本版不承诺所有 Linux 桌面都有托盘。
