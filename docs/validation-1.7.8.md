## 实现与边界

- 已实现实际媒体能力提示、约 200 ms 范围联动、下载中独立解析/预览和追加队列、任务/来源/批次取消、暂停队列及单任务暂停恢复。
- 状态有语义色及文字，失败原因独立查看，行内提供重试/目录/暂停操作；本轮进度、速度及标题/托盘反馈共用统计口径。详情默认显示用户信息，诊断按白名单复制。
- 草稿显示 UP 主与异步封面，信息与 JSON 移入结果菜单，预览使用冲突表格；设置分为下载、外观、系统集成，提供默认画质/编码、命名模板、代理和 1–4 项媒体并发。业务默认对新提交任务生效，已提交参数保持快照。
- 单任务续传仅在本次会话内恢复；有可靠资源标识且服务器正确响应 Range/If-Range 时续传，资源变化或不支持时安全重下。校验/合并完成当前阶段后等待，不提供跨重启历史/续传或限速。
- 权限提示以当前选集实际流为准；未知选集不冒充不可用，不将缺少档位一律归为大会员限制。执行仍重新读取并检查身份、权限及文件冲突。
