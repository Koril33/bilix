# 项目页面维护

`bilix.html` 是项目介绍/下载页面的唯一交付文件，目标替换现有 `/project/bilix.html`。它保留现有页面的深色背景、原背景图、半透明介绍面板、绿色按钮、GitHub/Gitee 链接和使用示例布局，更新过时的安装与命令说明。

CSS、JavaScript 和原背景图（JPEG data URI）全部内嵌，没有构建步骤、外部字体或框架。背景图无需额外上传。页面只在加载时尝试查询 GitHub 最新发行元数据；离线、超时或 API 限流时保留可用的发行页链接，不隐藏下载按钮。命令与说明在关闭 JavaScript 后仍可读。

## 本地预览

```shell
python -m http.server 8765 --bind 127.0.0.1 --directory site
```

打开 `http://127.0.0.1:8765/bilix.html`；也能直接打开本地文件。

## 发布前检查

- 对照线上页面检查背景、配色、介绍区、下载按钮与使用示例。
- 查看宽屏和 390px / 320px 手机布局；长命令只在代码块内横向滚动。
- 测试版本查询成功、失败和禁用 JavaScript 时的下载链接。
- 用键盘访问下载与文档链接；减少动画偏好下不执行按钮过渡。
- 核对 GitHub/Gitee、PyPI 与文档链接，以及当前 CLI 命令与实际支持范围。
- 更新补全章节的最低支持版本。下载按钮只查询已正式发布的最新版，不将开发版本标为已发布。

只需将该 HTML 复制到现有网站的 `project/bilix.html` 并通过网站原有流程发布。仓库不自动部署线上页面。
