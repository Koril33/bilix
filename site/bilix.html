使用示例

以下示例用于 Windows PowerShell：下载并解压发行包，在 bilix.exe 所在目录打开终端，用 .\bilix.exe 运行。Python 版将它替换为 blx 或 bilix。

帮助信息

.\bilix.exe --help
.\bilix.exe download --help

二维码登录及查看登录状态

.\bilix.exe auth login
.\bilix.exe auth status

用手机 Bilibili App 扫码并确认。凭据保存在当前用户的配置目录；用 config 查询位置，用 auth logout 删除本地凭据。

查看指定视频的清晰度、编码和音轨信息

.\bilix.exe info "https://www.bilibili.com/video/BV1j4411W7F7"

下载普通视频

.\bilix.exe download "https://www.bilibili.com/video/BV1j4411W7F7"

指定下载目录，例如当前目录下的 videos 文件夹

.\bilix.exe download -s "videos" "https://www.bilibili.com/video/BV1j4411W7F7"

指定清晰度、编码和音轨

.\bilix.exe download BV1j4411W7F7 -q 1080p --codec HEVC
.\bilix.exe download BV1j4411W7F7 --audio best

默认下载当前账号可获取的最高视频清晰度与 AAC 音轨。清晰度或编码不可用时提示降级；加 --strict 要求精确匹配。音轨可选 aac、flac、dolby、best，取决于该视频与当前账号的权限。

多 P、番剧选集与电影语言版本

.\bilix.exe download BV12R4y1J75d --page 1,3,5-7
.\bilix.exe download "https://www.bilibili.com/bangumi/play/ss28223035" --page 1

多 P、ss/md 默认选择全部正片选集；ep 选择单集。--page 可指定集数或语言版本，并覆盖 URL 中的选集参数。

下载多个视频 — 方式一：命令中指定多个 URL

.\bilix.exe download "https://www.bilibili.com/video/BV1yt4y1Q7SS" "https://www.bilibili.com/video/BV1j4411W7F7"

下载多个视频 — 方式二：多个 URL 写入一个文件，一行一个 URL

.\bilix.exe download --file "url_list.txt"

列表使用 UTF-8 编码，每行一个 URL 或 BV 号，支持空行与 # 注释。已有同名文件默认跳过；--overwrite 在新文件完成下载、校验与合并后替换旧文件。失败保留临时材料，目前不支持自动续传。

先查看下载计划，再开始下载

.\bilix.exe download BV1j4411W7F7 --dry-run

Python 版安装（Windows / macOS / Linux）

uv tool install djhx-bilix
blx --help
blx auth login
blx download BV1j4411W7F7

需要 Python 3.11 或更新版本，也支持 pip install djhx-bilix。更新使用 uv tool upgrade djhx-bilix。Windows 包内置 FFmpeg；macOS / Linux 需要安装 FFmpeg 并加入 PATH，或用 --ffmpeg 指定。运行 blx doctor 检查本地环境。

Tab 补全与指令纠错（1.5.0 起）

以下命令从 1.5.0 起支持。旧版用户请先升级 Python 包或下载新的 Windows 发行包。

# Windows PowerShell 当前会话
.\bilix.exe completion powershell | Out-String | Invoke-Expression

# Bash 当前会话（Python 版）
eval "$(blx completion bash)"

支持 Bash、Zsh、Fish、PowerShell 5.1/7，可补全命令、选项、清晰度、编码、音轨和本地路径。拼错指令会提示相近写法。持久启用方式见 补全文档。

账号权限与 DRM

大会员不代表拥有所有影片的下载权限，还需考虑单独购买、地区及具体媒体限制。登录权限与 DRM 解密授权是不同事项；当前程序不支持 DRM 媒体，也不会将试看保存为完整正片。遇到 DRM 提示请使用官方客户端播放，并查看该内容是否提供官方离线缓存。
